# NOTICES

## Inspirations

agate's review-role archetypes (Staff Engineer review, CEO, Engineering
Manager, Senior Designer, QA, CSO, Debug Expert) are conceptually inspired by
[gstack](https://github.com/garrytan/gstack) by Garry Tan (MIT-licensed), a
set of AI-agent role commands.

agate re-implements these role *archetypes* in its own execution/review
separation model. The file contents, role definitions, and workflow are
independently authored and do not derive from gstack's source — gstack's
code is not bundled, copied, or linked by agate.

For provenance:

- `review.md` (/review — Staff Engineer archetype)
- `plan-ceo-review.md` (/plan-ceo-review — CEO archetype)
- `plan-eng-review.md` (/plan-eng-review — Engineering Manager archetype)
- `design-review.md` (/design-review — Senior Designer + Frontend archetype)
- `plan-design-review.md` (/plan-design-review — Design Review archetype)
- `qa.md` (/qa — QA archetype)
- `investigate.md` (/investigate — Debug Expert archetype)
- `cso.md` (/cso — Security Officer archetype)

> Note: `office-hours.md` was removed from the role set; it is no longer
> shipped and is excluded from this notice.
