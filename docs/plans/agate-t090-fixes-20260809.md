### Task 1: 问题1 — PROD_TOUCHED 标记检测收紧（提及 vs 声明）

**Files:**

**关键（评审确认）**：

- **既有测试 IT_PT_BINARY.4/.5 的预期必须反转**：它们正是"句中提及"场景，之前断言失败（被误拦），现在应断言**通过**。这是 T090 定义的缺陷修正，不是回归。

- [ ] **Step 1: agate-summary.sh 加副本漂移检查（用 $SCRIPT_DIR）**

在 agate-summary.sh 加：

```bash
# 问题5 (T090)：检测项目 scripts/ 本地副本与权威版本漂移
# 权威版本 = $SCRIPT_DIR（本脚本所在 agate/scripts/）；项目副本 = 当前目录的 scripts/
_check_copy_drift() {
    local script
    for script in check-tdd-red.sh check-gate.sh check-pruning.sh; do
        if [ -f "scripts/$script" ] && [ -f "$SCRIPT_DIR/$script" ]; then
            if ! cmp -s "scripts/$script" "$SCRIPT_DIR/$script"; then
                echo "⚠️  scripts/$script 与 agate 权威版本不一致——本地副本可能已过期，建议改用 {agate_root}/scripts/ 或转发脚本" >&2
            fi
        fi
    done
}
_check_copy_drift
```

> 关键：权威路径用 `$SCRIPT_DIR`（脚本所在目录），**不能**用 `$AGATE_ROOT`（未定义，set -u crash）。`scripts/$script` 相对当前 cwd（项目根）——在项目根运行 agate-summary.sh 时正确。
